# Косметик-Про — Система оформления заказов

## 1. Название приложения
**Косметик-Про** — приложение для автоматизации продаж косметики (средств ухода и декоративной косметики).

## 2. Используемые технологии
- **Язык программирования:** Python 3.13+
- **Графический интерфейс (GUI):** PySide6 6.8+
- **СУБД:** PostgreSQL 18.6
- **Драйвер базы данных:** psycopg2-binary 2.9.10+

## 3. Назначение и основные функции
Приложение предназначено для выбора позиций из каталога, оформления и управления заказами. 
Реализованный функционал:
- Авторизация по логину (без пароля) с разграничением прав доступа (Гость, Клиент, Менеджер, Администратор).
- Просмотр каталога товаров с изображениями (и заглушкой при их отсутствии).
- Динамический расчет скидки (25% для товаров, не заказывавшихся последний месяц).
- Цветовая индикация остатков и скидок (голубой — нет на складе, красный — мало, зеленая цена — скидка >15%).
- Поиск, фильтрация по категориям и сортировка по цене в реальном времени.
- Корзина для формирования заказа и его оформление.
- Просмотр, удаление заказов и состава заказов для ролей Менеджер и Администратор.

## 4. Порядок подготовки базы данных и запуска приложения
1. Установите и запустите PostgreSQL 18.6.
2. Создайте базу данных `cosmetic_pro_db`.
3. Восстановите базу данных, выполнив SQL-скрипт из папки `src/db/cosmetic_pro.sql` (или `cosmetic_pro.db`) в pgAdmin.
4. Установите необходимые библиотеки Python:
   ```bash
   pip install PySide6 psycopg2-binary
