# Косметик-Про — Система оформления заказов

## 1. Название приложения
**Косметик-Про** — приложение для автоматизации продаж косметики.

## 2. Используемые технологии
- **Язык:** Python 3.13+
- **GUI:** PySide6 6.8+
- **СУБД:** PostgreSQL 18
- **Драйвер БД:** psycopg2-binary

## 3. Назначение и основные функции
Приложение предназначено для просмотра каталога товаров, оформления заказов и управления ими.
- Авторизация по логину (без пароля) с ролями (Гость, Клиент, Менеджер, Администратор).
- Просмотр каталога с изображениями и заглушками.
- Расчет скидки 25% для товаров без заказов за последний месяц.
- Цветовая индикация (голубой — нет на складе, красный — мало, зеленый — скидка).
- Поиск, фильтрация и сортировка.
- Корзина и оформление заказа.
- Просмотр состава заказов для менеджеров и администраторов.

## 4. Порядок запуска
1. Установите PostgreSQL 18 и создайте БД `cosmetic_pro_db`.
2. Выполните скрипт `src/db/cosmetic_pro.sql` в pgAdmin.
3. Установите зависимости: `pip install PySide6 psycopg2-binary`
4. Запустите: `python src/app/run.py`
